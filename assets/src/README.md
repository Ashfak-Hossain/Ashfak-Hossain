# Profile assets

Every SVG in `assets/` is generated by `build.mjs`. Text is converted to vector
outlines (Inter + JetBrains Mono) so it renders identically on every OS — GitHub
shows README SVGs inside `<img>`, where web fonts can't load.

```bash
cd assets/src
npm install
npm run build      # rewrites ../*.svg
```

Edit the `CONTENT` block at the top of `build.mjs` to change the name, tagline,
status pill, project cards or toolbox; colours live in `THEMES`.
Every animation respects `prefers-reduced-motion`.
